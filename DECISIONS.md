# Architectural & Specification Decisions (DECISIONS.md)

1. **Seeded PRNG**: Use `mulberry32` hashed from `layer.id + seed` for all random behavior (`particles`, `blob` wobble, `wiggle`, `noise`, `rand`, `glitch`) so `renderFrame(t)` is 100% pure and identical across preview and export.
2. **Expression Evaluator**: Implement a dedicated recursive-descent mathematical expression parser in `src/core/expr.ts` rather than `new Function` so expressions never allocate closures per frame and cannot access global scope.
3. **Multiple Overlapping `to` Macros**: Evaluate `to` macros sequentially in `at` timestamp order, capturing the accumulated transform state at each macro's start time so chained moves transition smoothly without jumping back to rest.
4. **Built-In Component Expansion**: Expand `{"type":"use","def":"..."}` at compile time into deterministic child layers wrapped in a logical group with `at`-relative stagger offsets (0.03s–0.12s) so flattened recipes can be inspected and exported directly.
5. **Text Measurement in Headless / Worker Contexts**: Use `OffscreenCanvas` / `HTMLCanvasElement` 2D context measurement when available, with a calibrated glyph-width fallback table for pure Node unit tests where DOM canvas is absent.
6. **Path Trim & Morph**: Implement SVG path command normalization (`M`, `L`, `C`, `Z`) in `0..100` coordinate space scaled to `w x h`, using `setLineDash` with total path length for `trimStart`/`trimEnd` and linear control-point interpolation for morphing matching path command sequences.
7. **Stateless Particle Simulation**: Compute each particle's lifecycle deterministically from `t - layer.t[0]` and particle index `0..count-1` using analytic kinematics (`p = p0 + v*dt + 0.5*g*dt^2`), supporting instant scrubbing to any frame in `O(count)` without stepping from `t=0`.
8. **Camera Follow Mode**: When a camera key specifies `{"follow":"layerId","lag":0.2}`, sample the target layer's position over a deterministic exponential decay kernel across `[0, t]` at fixed `1/fps` substeps so camera lag remains a pure function of `t`.
9. **Safe-Area Simulation**: Sample each layer at 5 representative timestamps across its active interval `[t0, t1]`, projecting its bounding box through parent, group, and camera zoom transforms (`0.5 + (x - cam_x) * zoom`) against the 2.5% canvas margin.
10. **Emoji Rendering Consistency**: Bundle `NotoColorEmoji` alongside `Sora`, `Inter`, and `Noto Sans Devanagari` in `src/assets/fonts/` and include it in every text and disc emoji font stack so emoji glyphs render identically across Android WebView and desktop Chromium.
11. **Zero-Slider Touch UI**: Replace all range sliders (timeline scrubbers, zoom controls, volume, duration, resolution/fps selectors) with a custom pointer/touch timeline scrub bar, `-1f / +1f` frame steppers, and 48dp segmented button groups.
12. **Long Video Streaming Sink**: Use an abstracted `ExportSink` that streams muxed chunks into OPFS / File System Access API / Android native `VideoSink` plugin (or chunked in-memory ArrayBuffer for short clips) to export 5-minute videos without exhausting mobile RAM.
13. **Color Interpolation Space**: Interpolate keyframe colors in linear RGB (`sRGB -> gamma 2.2 linear -> lerp -> sRGB`) in `interpolateHexColor` for perceptually smooth, bright mid-tones without muddy sRGB darkening.
14. **Expression Closure Compilation**: Compile SPEC 8d expressions once via a Pratt parser (`compileExpression`) into cached pure closures `(ctx: ExprContext) => number` supporting arithmetic, comparisons (`<, >, <=, >=, ==, !=`), ternary (`a ? b : c`), and whitelisted math/noise functions without `eval` or `new Function`.
15. **MP4 Container FastStart Layout**: Use non-fragmented MP4 layout (`fastStart: false` with `StreamTarget` random-access header patching at finalize via `RandomAccessFile` on Android and random-access byte buffer in Web) for maximum hardware player and social-platform compatibility.
16. **Glow & Shadow Sprite Caching**: Cache pre-blurred glow and drop-shadow sprites per `(shapeKind, quantizedSize, radius, color, blurRadius)` in a 24 MB memory-capped LRU cache (`src/render/sprites.ts`) and modulate `globalAlpha` for animated glow strength instead of invoking `ctx.shadowBlur` on large shapes every frame.
17. **Video Layer Frame Fetching**: Use `HTMLVideoElement` seek-based frame extraction with `registerLoadedVideoAsset` (and `crop`/`anchor`/`kenburns` transforms) for deterministic preview and export without duplicating full decoded raw YUV buffers in RAM.
18. **Long Export Segmentation**: Stream encoded video and 48 kHz resampled stereo audio chunks in 2 MB batches through `StreamTarget` into a single unbroken timestamp container (`RandomAccessFile` on Android / `FileSystemWritableFileStream` on desktop) to avoid multi-segment remux drift while keeping memory bounded.
